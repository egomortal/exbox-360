The editor retains six exact companion files: the unchanged baseline five plus `assets/ui/sort-filter-legend.rle`. `companion_producer.py` generates them locally; `companion-inputs.json` records supported user-input hashes. No artwork or fonts are included.

Supply your original supported editor XEX and `xenonclatin.xtt`. `extract_editor_ui.py` obtains the nine required PNGs automatically. It can build the hash-pinned extraction tool from source you supply, using a local C++17 compiler, or use your existing compatible tool. Its source, keys and executable are not included in this download. The companion generator validates the extracted PNGs, converts the original font, renders the prompt/legend, and verifies the resulting hashes. Verified rasterizer versions are recorded in the contract; different rasterizer output is rejected.

Extraction API: `extract_from_xex(xex_path,fresh_work,tool_source=source_folder,compiler='c++')` builds the supplied source, runs its self-test, extracts the image and returns a PASS receipt with `ui_directory`. Pass that folder to `generate_from_originals`. An existing compatible extractor can instead be selected with `tool=executable_path`. The source contract contains hashes only; no title bodies or extracted assets are distributed.

`extract_xtt_font.py` converts your original XTT outlines to a standard TTF. Font data is supplied by you. `icon0.png` is an original procedural solid-color512x512image; `param.json` is authored application metadata. Both reproduce the existing required files.

The libc companion is the PS5_Vulkan clean-room runtime shim. `build_libc(vulkan_source,compiler,self_tool,work)` compiles the hash-pinned builder source with your C++20compiler, generates rawELF from the two supplied manifests, and wraps it with your locally built PS5_Vulkan `ps5-native-tool`. It runs twice and verifies both exact hashes. The work folder must be fresh and separate from dependency sources; logs and failed outputs are preserved. The function performs no downloads or installation. The supported upstream producer is PS5_Vulkan `tools/rebuild-libc.sh`; this module reproduces its local compile/generate/wrap steps without its dependency-download step. The C++builder and tool sources are supplied externally and retain their own licenses.

Python APIs: `generate_from_originals(ui_png_folder,xtt_path,libc_path)` returns all six validated byte strings. `generate(ui_png_folder,ttf_path,libc_path)` accepts the exact preconverted font. Integration must write returned bytes only to the isolated local package output, after its gates pass. No console, FTP or publishing action is performed by these modules.
