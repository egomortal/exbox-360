# Avatar Editor

The native Avatar Editor title (PPSA99734) is built on your own PC from your own original files.

- [`local-builder/`](local-builder/README.md) is the Windows builder app: double-click **Start Builder.cmd**,
  choose your folders and press **Build**.
- The code the dashboard uses to open the editor and come back is in
  [`../dashboard/modules/avatar_editor/`](../dashboard/modules/avatar_editor/).

No editor binary, game files, fonts or artwork are included.
