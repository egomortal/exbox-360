# ExBox360-PS5

> **Microsoft says everything is an Xbox. PlayStation says play has no limits.
> We took them both at their word.**

An Xbox-360-style dashboard — and its matching avatar editor — that run **natively on a jailbroken PS5**.
Built to install together with one click: point the installer at your console, tick **Install everything (recommended)**, press **Run**.

- `dashboard` / native title — the Ex-Box 360 experience (blades, avatars, music, video, 4K).
- `modules/avatar_editor` — the avatar editor, launched from the dashboard.
- installer — one-drop setup, with backup & one-click **Restore**.

See `README-NATIVE.md` and `README-EXPORT.md` for build and export details.
